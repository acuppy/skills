# Personal

Skills tied to my own setup, not promoted in the plugin.

- **[be-critical](./be-critical/SKILL.md)** — Deliver a direct, unsugarcoated critique of the approach, plan, or design currently under discussion.
- **[brief](./brief/SKILL.md)** — Condense the previous verbose response into a tight, skimmable brief.
- **[conduct](./conduct/SKILL.md)** — Orchestrate a coding prompt across a model hierarchy, verifying work mechanically and against plan before final review.
- **[edit-article](./edit-article/SKILL.md)** — Edit and improve articles by restructuring sections, improving clarity, and tightening prose.
- **[obsidian-vault](./obsidian-vault/SKILL.md)** — Search, create, and manage notes in an Obsidian vault with wikilinks and index notes.
- **[recap](./recap/SKILL.md)** — Deliver a concise re-entry briefing scoped to the current project and conversation.
- **[session-title](./session-title/SKILL.md)** — Recommend a short list of titles for the current session, derived from what the conversation is actually about.
- **[to-skill](./to-skill/SKILL.md)** — Distill the current session into a reusable skill by extracting its repeatable core.
